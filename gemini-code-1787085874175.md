# Skill: Mall Navigation Graph Generator

## Objetivo
Analizar 3 planos vectoriales (SVG) de una plaza comercial y 3 imágenes de leyendas (PNG) para generar un grafo de navegación en formato JSON. El grafo será consumido por un algoritmo A* (A-Star) para enrutamiento interno.

## Entradas (Inputs)
1. **Mapas Base:** `nivel_inferior.svg`, `nivel_principal.svg`, `nivel_superior.svg`. (Contienen los polígonos de los locales comerciales y las rutas trazadas).
2. **Leyendas (Diccionarios):** `image_91b6d3.png`, `image_91ba0f.png`, `image_91ba4d.png`. (Contienen el mapeo de IDs numéricos a nombres reales de tiendas e islas).

## Instrucciones de Ejecución

### Fase 1: Extracción Semántica (OCR)
1. Lee las imágenes de las leyendas.
2. Extrae el texto y clasifícalo en dos categorías estables por nivel: `stores` e `islands`.
3. Crea un diccionario temporal en memoria: `{ "Nivel_Inferior": { "store_1": "Liverpool", "island_1": "Casa Carcasa" ... } }`.

### Fase 2: Procesamiento Espacial (Parseo SVG)
1. Analiza los archivos SVG. Localiza los centroides (x, y) de cada bloque identificable.
2. Identifica los nodos de intersección de pasillos (`corridor_intersection`) y los nodos de transición vertical (`portal_escalator`, `portal_elevator`).
3. Asocia cada polígono del SVG con su respectivo ID numérico y haz un cruce (merge) con el diccionario extraído en la Fase 1.

### Fase 3: Construcción de Aristas (Edges)
1. Conecta los nodos adyacentes dentro del mismo nivel (solo donde exista espacio caminable).
2. Calcula la distancia euclidiana entre nodos conectados para asignar el valor `weight`.
3. Conecta los nodos `portal` entre los diferentes niveles, asignando una penalización estática al `weight` (ej. +50 para escaleras, +150 para elevadores).

### Fase 4: Generación de Anclajes (Landmarks)
1. Si un nodo de tipo `corridor_intersection` está a una distancia euclidiana mínima de un nodo de tipo `island` o `anchor_store` (ej. Liverpool, Chedraui, Sears), inyecta el nombre de ese comercio en el atributo `context_element` del nodo de intersección.

## Esquema de Salida Esperado (JSON)
Devuelve un archivo `mall_graph.json` con la siguiente estructura estricta:

```json
{
  "metadata": {
    "version": "1.0",
    "total_nodes": 0
  },
  "nodes": [

      "type": "anchor_store",
      "name": "Liverpool",
      "coordinates": { "x": 145, "y": 890 },
      "context_element": null
    },
    {
      "id": "n_lvl2_intersect_4",
      "level": 2,
      "type": "corridor_intersection",

    }
  ]
}
